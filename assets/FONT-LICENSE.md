# Font licence

`plus-jakarta-sans-latin.woff2` is a Latin subset of **Plus Jakarta Sans**
(Tokotype), distributed under the **SIL Open Font License 1.1**.

- Project: https://github.com/tokotype/PlusJakartaSans
- Licence: https://openfontlicense.org/

The OFL permits bundling and self-hosting the font with a website. The font is
served from this repository rather than a third-party CDN, so the site makes no
external requests.

The `OutRes` wordmark in `logo-wordmark*.svg` and `logo-lockup*.svg` was produced
by converting glyphs from this font to outlines. Under the OFL this is permitted:
outlined artwork derived from an OFL font is not itself bound by the licence.
